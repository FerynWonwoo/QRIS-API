    4. ENDPOINT
    Server: http://127.0.0.1:8000
    Authorization: Bearer <access_token> (endpoint terlindungi)

    GET /api/ping - Publik
    POST /api/login - Publik
    GET /api/me - User dan Admin

    MERCHANTS
    GET /api/merchants - User dan Admin - Read
    POST /api/merchants - User dan Admin - Create
    GET /api/merchants/{id} - User dan Admin - Read detail
    PUT/PATCH /api/merchants/{id} - User dan Admin - Update
    DELETE /api/merchants/{id} - Admin - Delete

    QRIS-CODES
    GET /api/qris-codes - User dan Admin - Read
    POST /api/qris-codes - User dan Admin - Create
    GET /api/qris-codes/{id} - User dan Admin - Read detail
    PUT/PATCH /api/qris-codes/{id} - User dan Admin - Update
    DELETE /api/qris-codes/{id} - Admin - Delete

    QRIS-TRANSACTIONS

    5. HAK AKSES
    User: CRU sesuai ownership dan aturan bisnis.
    Admin: CRUD sesuai aturan bisnis.
    User hanya dapat mengubah transaksi miliknya menjadi failed sesuai transisi status yang diizinkan. Konfirmasi paid dilakukan admin.
    QRIS Code merupakan simulasi pembayaran.
    Tabel pendukung: users dan settlement_transactions.

    6. CARA MENJALANKAN
    composer install
    Buat database qris_db dan sesuaikan konfigurasi .env dengan MySQL lokal.
    php artisan migrate --seed
    php artisan serve
